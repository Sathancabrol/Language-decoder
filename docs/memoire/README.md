# Mémoire extraite

Couche **mémoire** (pas le journal). Sources : `docs/conversations/`. Machine : `data/memoire.json`.

## Décisions en vigueur

1. Inférence probabiliste, jamais lecture d’émotion.
2. Conversation ≠ mémoire ; l’original reste.
3. HTML5 local, pas de CDN.
4. Minimisation par modalité.
5. PAM en V1→V4, pas d’usine à gaz.
6. Visuel Cognitorium sans fausse précision.
7. 2040 = horizons, l’humain décide de l’éthique.
8. Le décodeur n’est pas un facteur d’authentification ni un dispositif médical.

## Idées à ne pas perdre

- Language Decoder = couche langages / interface de Cognitorium.
- Conversation as a first-class object.
- « Continuer avec une IA » comme feature.
- Une mémoire externe, plusieurs interfaces LLM.
- Format journée-type (timeline + 4 KPI + avant/après) pour les livrables.
