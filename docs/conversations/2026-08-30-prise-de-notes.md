## Ce que la page fait

Pas un texte linéaire : mots-clés, flèches, embranchements. Passage d’une liste à un **modèle relationnel**.

Deux gravités :

1. **Cognitorium** — personne, cognition, compétences, activités, formations, métiers, parcours. Cinq couches à ne pas confondre. Compatibilité plutôt que classement (« dans quelles conditions s’épanouir ? »).
2. **Language Decoder** (droite de la page) — science → langages de l’objet humain (parole, geste, BPM, BCI) → inférer un état à T avec T1, T2… → se représenter comme on apprend une langue → créer l’interface.

## Décisions déjà tirées

- Probabiliste, pas lecture intérieure.
- Signal isolé ≠ émotion. FC élevée : effort, excitation, stress, peur, douleur, déplacement.
- Ligne de base individuelle.
- JSON de représentation : données / hypothèses / action.
- Interface adaptative, explicable, réversible, sans diagnostic.

Principe : *Observer les signes, comprendre le contexte, représenter les états, anticiper les besoins et adapter l’interface.*
