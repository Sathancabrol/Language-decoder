Comment lire cet écran

Chaque objet a quatre informations. C’est la même grille partout.

  1. Titre — de quoi il s’agit, en une phrase.
  2. Nom — le nom précis (ex. Charge cognitive, FC).
  3. Catégorie visuelle — la famille et sa couleur.
  4. Features / action — ce que ça montre, ce que vous pouvez faire.
  • K Science — ce que la recherche définit. Pas une personne.
  • E Preuves — features observées. Pas le tracé brut.
  • I Inférences — conclusion avec intervalle, ou refus.
  • R Refus — le modèle n’invente pas. Rose uniquement ici.

Un pourcentage seul n’existe pas : toujours point + [bas–haut]. Vous tranchez : proposer une aide, ignorer, corriger, refuser.
